SIOS

Silicon OS / Superintelligent OS

A compact, local-first utility layer from Superintelligent Silicon — files, keys, calculator, calendar, notes — interoperable, exportable, calm. Built to open in a page or on a machine. Not a cloud desktop. Not vapor dressed as a launch.

Open shell preview View on GitHub
Honest status. Phase 0 scaffold only — public vision, MIT license, and a live in-browser desktop preview with dock stubs. No crypto. No key collection. No downloadable product yet.

Planned modules

  • Files Local tree, exportable
  • Keys Encrypt on-device; keys never leave without you
  • Calc Simple, history export
  • Calendar Local events + ICS
