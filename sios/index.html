SIOS

Silicon OS / Superintelligent OS

A compact, local-first utility layer from Superintelligent Silicon — files, keys, calculator, calendar, notes — interoperable, exportable, calm. Built to open in a page or on a machine. Not a cloud desktop. Not vapor dressed as a launch.

Open the live shell View on GitHub
Honest status. Phase 0.5 — Files + Keys + Calc + Calendar — public vision, MIT license, and a live in-browser desktop preview. Files, Keys, Calc, and Calendar work locally, with a local data bus (Save to Files). Keys uses on-device Web Crypto (not audited). No key collection or network upload.

Planned modules

  • Files Live virtual FS · editor + JSON import/export
  • Keys Live · PBKDF2+AES-GCM · not audited · local-only
  • Calc Live in shell preview · history + JSON export
  • Calendar Live in shell · events + JSON import/export
