SIOS

Silicon OS / Superintelligent OS

A compact, local-first utility layer from Superintelligent Silicon — files, keys, calculator, calendar, notes — interoperable, exportable, calm. Built to open in a page or on a machine. Not a cloud desktop. Not vapor dressed as a launch.

Open the live shell View on GitHub
Honest status. Phase 1a — Files, Notes, Settings, Keys, Calc, and Calendar in a live in-browser shell, with IndexedDB storage, strict CSP, a local data bus, and clearly labeled UNENCRYPTED ZIP backup. Keys uses on-device Web Crypto PBKDF2 (600k; not audited). No accounts. No key collection or network upload from the shell.

Modules

  • Files Live virtual FS · IndexedDB · JSON import/export
  • Notes Live · .md in Files/Notes · plain text (no HTML)
  • Settings Live · theme · lock timeout · storage · ZIP backup
  • Keys Live · PBKDF2 600k + AES-GCM · not audited · local-only
  • Calc Live · history + Save to Files
  • Calendar Live · events + JSON import/export
